# LC-3 ARCHITECTURE VM

How to use : 

1. clone the repo   
```bash
git clone https://github.com/NaveenGadugina678/lc3-vm.git
cd lc3-vm
```
2. compile the code  
```bash
gcc lc3.c -o lc3-vm
```
3. run the games
```bash
./lc3-vm games/2048.obj or  
./lc3-vm games/rogue.obj
```

---

For more information about code and how to build it,  
[check this out!!](https://www.jmeiners.com/lc3-vm/)
